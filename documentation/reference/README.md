# Reference

Quick lookup materials and reference documentation.

## Purpose

This folder contains reference materials that are looked up frequently but don't require step-by-step instructions. These are quick-lookup documents for specific information.

## When to Use This Folder

Create reference documentation when:
- ✅ You're answering "What can I call?"
- ✅ You're providing a quick lookup
- ✅ You're documenting commands or syntax
- ✅ You're creating a glossary or terminology list
- ✅ You're listing environment variables or configuration
- ✅ The document is referenced frequently (6+ months)
