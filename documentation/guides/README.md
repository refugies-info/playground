# Guides

Step-by-step how-to guides for common tasks and workflows.

## Purpose

This folder contains practical, actionable guides that help developers and users accomplish specific tasks. Each guide is a tutorial or walkthrough designed to be followed from start to finish.

## When to Use This Folder

Create a guide when:
- ✅ You're explaining "How do I...?"
- ✅ You're providing step-by-step instructions
- ✅ You're documenting a setup or configuration process
- ✅ You're walking through a workflow or procedure
- ✅ The guide will be useful repeatedly (6+ months)
