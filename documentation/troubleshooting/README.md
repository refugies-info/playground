# Troubleshooting

Common issues, problems, and their solutions.

## Purpose

This folder contains troubleshooting guides and solutions for common problems that developers might encounter. Each document addresses specific issues and provides solutions.

## When to Use This Folder

Create troubleshooting documentation when:
- ✅ You're answering "What went wrong?"
- ✅ You're documenting common errors
- ✅ You're providing solutions to problems
- ✅ You're explaining error messages
- ✅ You're documenting debugging techniques
- ✅ The issue will recur (6+ months)
