# Workflows

Feature-specific workflows and business processes.

## Purpose

This folder contains documentation about workflows and processes specific to features or business domains. These describe how tasks flow through the system and what steps are involved.

## When to Use This Folder

Create workflow documentation when:
- ✅ You're explaining "What's the process?"
- ✅ You're documenting a business workflow
- ✅ You're describing a feature-specific process
- ✅ You're documenting multi-step procedures
- ✅ The workflow involves multiple systems or roles
- ✅ The documentation will be useful long-term (6+ months)
