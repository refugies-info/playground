# Architecture

System design, technical decisions, and architectural documentation.

## Purpose

This folder contains documentation about how the system is designed and why certain architectural decisions were made. It explains the "why" behind the technology choices and system structure.

## When to Use This Folder

Create architecture documentation when:
- ✅ You're explaining "How does this work?"
- ✅ You're documenting system design
- ✅ You're explaining architectural decisions
- ✅ You're describing the overall structure
- ✅ You're documenting design patterns
- ✅ The documentation will be useful long-term (6+ months)
