# Roadmaps

Project roadmaps, timelines, and milestones.

## Purpose

This folder contains project roadmaps and timeline documentation. These documents outline planned features, phases, and milestones for the project.

## When to Use This Folder

Create roadmap documentation when:
- ✅ You're answering "When will this happen?"
- ✅ You're documenting project phases
- ✅ You're outlining planned features
- ✅ You're creating a timeline
- ✅ You're defining milestones
- ✅ The roadmap will be referenced long-term (6+ months)
