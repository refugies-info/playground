# API Reference

Technical API documentation and integration guides.

## Purpose

This folder contains API reference documentation for external and internal APIs. These documents describe how to use APIs, what endpoints are available, and how to integrate with them.

## When to Use This Folder

Create API documentation when:
- ✅ You're documenting an API
- ✅ You're describing API endpoints
- ✅ You're explaining how to use a service
- ✅ You're documenting integration points
- ✅ You're providing technical integration guides
- ✅ The documentation will be referenced long-term (6+ months)
