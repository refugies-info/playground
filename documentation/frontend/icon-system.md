# Icon System

Architecture, conventions, and usage of icons in the design system.

---

## Architecture

The `@playground/ui/icons` barrel unifies two icon sources into a single import:

| Source | Prefix | Examples | Count |
|--------|--------|----------|-------|
| [Remix Icons](https://remixicon.com/) (`@remixicon/react`) | `Ri` | `RiArrowRightLine`, `RiSearchLine` | ~2800 |
| DSFR custom (auto-generated from `@gouvfr/dsfr`) | `Fr` | `FrErrorFill`, `FrInfoLine` | ~45 |

DSFR custom icons are those created by the DSFR team (accessibility, statuses, logos) that don't exist in Remix Icons.

### File structure

```
packages/ui/
├── scripts/
│   └── sync-dsfr-icons.ts              # Generates DSFR custom components
└── src/
    ├── icons.ts                         # Barrel (2 re-exports)
    └── primitives/icon/
        ├── Icon.tsx                      # Wrapper component
        ├── index.ts
        └── custom-icons/dsfr/           # Auto-generated by sync-dsfr-icons.ts
            ├── index.ts                  # Barrel
            ├── FrErrorFill.tsx
            ├── FrInfoLine.tsx
            └── ...
```

### Barrel (`icons.ts`)

```ts
export * from "@remixicon/react"                    // ~2800 Ri* icons
export * from "./primitives/icon/custom-icons/dsfr"  // ~45 DSFR custom icons
```

## Usage

### Import

```tsx
import { RiArrowRightLine, RiSearchLine, FrInfoLine } from "@playground/ui/icons"
```

Single import, TypeScript autocomplete across all ~2845 icons.

### `<Icon>` component

Wrapper with DSFR-aligned sizes and automatic accessibility.

```tsx
import { Icon } from "@playground/ui"
import { RiSearchLine } from "@playground/ui/icons"

// Decorative icon (aria-hidden="true")
<Icon icon={RiSearchLine} size="md" />

// Meaningful icon (role="img" + aria-label)
<Icon icon={RiSearchLine} size="md" aria-label="Search" />
```

#### Sizes

| Size | Pixels | DSFR class |
|------|--------|------------|
| `xs` | 12px | `fr-icon--xs` |
| `sm` | 16px | `fr-icon--sm` |
| `md` | 24px | `fr-icon--md` (default) |
| `lg` | 32px | `fr-icon--lg` |

### In a Button

The `leftIcon` and `rightIcon` props accept an `IconRef`.

```tsx
import { Button } from "@playground/ui"
import { RiArrowRightLine, RiCloseLine } from "@playground/ui/icons"

// Button with left icon
<Button leftIcon={RiArrowRightLine}>Continue</Button>

// Icon-only button (auto-detected: no children → square padding)
<Button leftIcon={RiCloseLine} aria-label="Close" />
```

Icon size adapts automatically to the button size:

| Button size | Icon size |
|-------------|-----------|
| `sm` (32px) | `sm` (16px) |
| `md` (40px) | `sm` (16px) |
| `lg` (48px) | `md` (24px) |

The loading spinner (`isLoading`) uses `RiLoader4Line` with `animate-spin`.

## Types

### `IconRef`

Type to use for icon slots in custom components.

```ts
import type { IconRef } from "@playground/ui"

interface MyComponentProps {
  icon?: IconRef
}
```

`IconRef` is an alias for `RemixiconComponentType` (exported from `@remixicon/react`).

### `IconSize`

```ts
import type { IconSize } from "@playground/ui"

type IconSize = "xs" | "sm" | "md" | "lg"
```

## Naming conventions

### Remix Icons → React component

| Remix name | Component | DSFR class |
|------------|-----------|------------|
| `arrow-right-line` | `RiArrowRightLine` | `fr-icon-arrow-right-line` |
| `search-line` | `RiSearchLine` | `fr-icon-search-line` |
| `checkbox-circle-fill` | `RiCheckboxCircleFill` | `fr-icon-checkbox-circle-fill` |

### DSFR custom → React component

| DSFR class | Component |
|------------|-----------|
| `fr-icon-error-fill` | `FrErrorFill` |
| `fr-icon-info-line` | `FrInfoLine` |
| `fr-icon-success-fill` | `FrSuccessFill` |
| `fr-icon-warning-fill` | `FrWarningFill` |
| `fr-icon-theme-fill` | `FrThemeFill` |
| `fr-icon-accessibility-fill` | `FrAccessibilityFill` |

## DSFR custom sync

DSFR custom icons are auto-generated by a TypeScript script.

```bash
# Run manually
pnpm --filter @playground/ui sync:icons

# Automatic after every pnpm install (postinstall hook)
```

The script:
1. Scans SVGs in `@gouvfr/dsfr/dist/icons/`
2. Compares against `@remixicon/react` exports
3. Generates one React `.tsx` component per missing icon
4. Generates the `index.ts` barrel

When `@gouvfr/dsfr` is upgraded, icons re-sync automatically on `pnpm install`.

See [documentation/scripts/sync-dsfr-icons.md](../scripts/sync-dsfr-icons.md) for details.

## Storybook

Stories in `apps/storybook/src/stories/ui/Icon.stories.tsx`:

- **Playground**: test a single icon with controls (size, aria-label)
- **Table**: all icons with search and category tabs (Arrows, Buildings, Communication, Custom DSFR, etc.)
- **Gallery**: display by category with React names and DSFR classes

The **Custom DSFR** tab groups icons whose name doesn't start with `Ri`.
